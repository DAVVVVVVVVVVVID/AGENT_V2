# Chat 模块实现任务清单

设计文档见 `chat_design.md`。

## 任务列表

| 编号 | 任务 | 依赖 |
|------|------|------|
| 01 | Sandbox API 扩展 | 无 |
| 02 | Store 扩展（Chat 记忆） | 无 |
| 03 | Perceive 扩展 | 01 |
| 04 | Think 工具扩展（主动发起） | 01 |
| 05 | 判断模块 | 01、02 |
| 06 | 对话循环模块 | 01、02 |
| 07 | Loop 集成 | 03、04、05、06 |
| 08 | 对话后处理 | 02、06、07 |
| 09 | UI Server 扩展 | 01 |
| 10 | 前端 Chat UI | 09 |

## 依赖图

```
01 (Sandbox API) ──┬──→ 03 (Perceive) ────────────┐
                   ├──→ 04 (Think Tools) ───────────┤
                   ├──→ 05 (Judgment) ──────────────┤──→ 07 (Loop) ──→ 08 (Aftermath)
                   ├──→ 06 (Chat Session) ──────────┘
                   └──→ 09 (UI Server) ──→ 10 (Frontend)

02 (Store) ─────────────────────────────────────────────→ 05、06、08
```

## 推荐实现顺序

**阶段一（并行）**：01 + 02
**阶段二（并行）**：03 + 04 + 05 + 06（均依赖 01 完成）
**阶段三**：07（依赖阶段二全部完成）
**阶段四（并行）**：08 + 09
**阶段五**：10（依赖 09 完成）
